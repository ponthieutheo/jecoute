# Médias de J’écoute

Liste des images et animations de `docs/media/`, avec une ligne de description pour chacune (elle sert de
texte alternatif). Données inventées seulement : aucune dictée, aucun réglage ni fichier réel.

- Captures de l’interface : PNG, nettes en 2x (fenêtre 696 × 609, image 1392 × 1218), 256 couleurs optimisées.
  Chaque écran existe en `-sombre` et `-clair` (afficher selon le thème du visiteur avec `<picture>`).
- Une image par fonction : PNG 2x, thème sombre, recadrée sur la fonction.
- Animations du perso : WebP animé, fond transparent, 25 images par seconde, en boucle.
- Descriptions : en français pour `fr/`, en anglais pour `en/`, dans les deux langues pour les bannières et `perso/`.
- Le dossier `perso/` est sous licence PolyForm Noncommercial 1.0.0 (voir `perso/LICENSE`) ; le reste suit la
  licence du dépôt.
